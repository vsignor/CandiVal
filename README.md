# PAO: *"CandiVal – Sweety Moments"*
Progetto realizzato per il corso di Programmazione ad Oggetti (A.A. 2018–2019. Università degli Studi di Padova, Corso di Laurea Triennale in Informatica.

## 🍰 Descrizione del Progetto

Il progetto consiste nello sviluppo di un’applicazione per la gestione di un negozio di dolci, con particolare attenzione alla gestione dei prodotti e delle ordinazioni.
Il sistema è pensato per l’utilizzo sia da parte del gestore del negozio sia dei clienti, offrendo funzionalità differenti in base al ruolo.

## ⚙️ Funzionalità principali

### 🛠️ Admin
* Creazione di nuovi sconti;
* Visualizzazione delle tipologie di prodotti disponibili;
* Gestione del magazzino e delle giacenze;
* Inserimento di nuovi sottotipi di prodotto (ingredienti, nome, ecc.);
* Gestione delle ordinazioni (visualizzazione e archiviazione);
* Avvio dell’interfaccia cliente;
* Modifica credenziali di accesso;
* Aggiornamento informazioni del negozio (orari, contatti, nome);
* Gestione e caricamento immagini dei prodotti.

### 👤 Cliente
* Visualizzazione dei prodotti disponibili;
* Creazione di ordini e gestione del pagamento.
